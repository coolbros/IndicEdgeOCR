# Phase 3.8 training pipeline audit

The pinned training recipe decodes OpenCV BGR, runs RecConAug then RecAug, encodes both heads for a shared transcription, and resizes after augmentation. The multiscale dataset preserves aspect ratio up to the canvas width, normalizes to [-1, 1] and pads with normalized zeros. Inference retains its previous wide-canvas behavior. Configuration allows a raw label length of 25, and the NRTR encoder rejects encoded lengths above 23 because of BOS and EOS. The bounded subset rejects partially encodable labels, independently of the baseline's existing skip-unknown encoding semantics.

The vendored TIA primitives have their original PaddleOCR Apache notices and are byte-identical to the pinned checkout. RecAug uses TIA distort, stretch and perspective on images at least 20 pixels in both dimensions. The remaining stages are crop, blur, HSV, jitter, Gaussian noise, and inversion, each with probability 0.4. Crop removes 1–8 rows at a random edge, blur uses a separable 5-tap Gaussian, and noise uses half the sampled normal variate with variance 0.1. RecConAug uses probability 0.5, up to two training peers, shared height 48 and the 320/48 ratio cap. The validation trainer caps merged labels at 23 so a concat cannot produce a label that upstream NRTR would reject. It keeps the original item rather than doing upstream recursive replacement when a concatenation candidate exceeds that cap. The decoded image cache sits before augmentation.

Default batch sizes are 64, 42 and 32 at heights 32, 48 and 64 and width 320. The bounded run uses first batch size 8, yielding 8, 5 and 4. Single-process sampling uses local seeded random state with per-epoch index and batch shuffling and wraps the final partial batch using the shuffled index prefix. Upstream constructs the initial index grouping once and subsequently shuffles batch IDs. The new sampler preserves scale scheduling and padding behavior while reshuffling sample groups across epochs. Distributed batching is outside this validation.

CTC runs the full logit sequence, not a cropped sequence inferred from padding. It uses blank 0 by default and averages unnormalized per-item CTC losses. Impossible repeated alignments can produce infinite loss. The production path reports nonfinite results and retains native Torch log-softmax. NRTR removes the first teacher-forced label from targets, predicts EOS, excludes PAD from the denominator and puts 0.9 mass on target and 0.1 over the other classes. The configuration exposes the equivalent indices for independent head sizes. Phase 3.8 keeps the causal mask and LayerNorm implementation.

The existing Adam applies coupled L2 and its three parameter groups implement the stem BN, CTC projection and other defaults. A paired CPU run used zero, 1e-5 and 3e-5 decay groups with identical FP32 parameters and gradients. Across two steps, parameter maximum errors were 3.638e-12 and 4.093e-11. The first moment maximums were 3.725e-9 and 7.451e-9, and the second moment maximums were 5.166e-10 and 2.197e-9. The tiny-gradient coordinate probes epsilon sensitivity. These measurements do not imply identical kernel ordering. The tested scheduler matched every one of 16 Paddle values exactly. It starts at zero, reaches base LR after warmup, and runs cosine with the full configured step denominator and warmup offset. [CPU paired reference](https://www.kaggle.com/code/agastyavar/indic-edge-ocr-phase38-reference-cpu/versions/1).

On the same fixed-logit CPU fixture, CTC loss and gradient maximum differences were 5.970e-4 and 8.585e-5, both outside the strict threshold. NRTR loss passed with max 6.866e-5, while its gradient missed at 1.766e-5. In Phase 3.6 all four fixed-logit T4 checks passed. The training pipeline does not alter the loss formulation to chase the CPU discrepancies.

The exact continuation unit test restores the midrun model, Adam moments, scheduler and RNG state, then reproduces the next update bit for bit on its CPU fixture. Training checkpoint payload and checksum sidecar use atomic replacements individually. An interrupted replacement between the two files is rejected at reload rather than silently accepting inconsistent state.
